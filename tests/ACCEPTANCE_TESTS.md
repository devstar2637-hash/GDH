# Acceptance tests AT-01..AT-14 (verifier-owned)

### (3) 인수 테스트 14개(천 개의 가게 기준)
소유자 B(Claude Code 검증자). 판정은 전부 코드가 하고 Argon은 tests/를 읽기만 한다. 공통 고정 입력: 성수동 카페, 예산 1억 2천만원, 36개월, 변형 1,000개, seed 고정. 입력 데이터는 공개 데이터(서울 열린데이터광장 상권분석 개업률·폐업률·추정매출, data.go.kr 상가정보·건축물대장)와 현장 입력(점포 조건·사진)을 실제 입력으로 쓰고, 합성값은 '합성' 라벨을 붙인 경우에만 허용한다. 기준값(±5%p, 10%, 2초)은 최종 보고서의 값이며 12:00 스파이크 실측으로 바뀔 수 있다. 결과는 14:25~14:45에 행마다 통과 / 실패 / 미확인으로 기록한다(실패는 실패로 적는다).

제출 가능 기준: AT-03~AT-07과 AT-10~AT-12, AT-14 전부 통과. AT-13(적대 3라운드)은 G2 뒤 첫 P1이므로 14:25 전에 끝나면 결과를 적고, 못 끝나면 '미실행'으로 적는다. AT-01이 실패하면 제출은 하되 '미보정' 라벨 경로(AT-02)로 가고, AT-09가 실패하면 '탐색기' 문구로 간다. 둘 다 실패를 숨기지 않는다. ReScene 폴백 시에는 최종 보고서 2순위 절의 게이트(재투영 IoU ≥ 0.4, 가감속 ≤ 9.0 m/s², 정지거리 닫힌 식 1% 일치, 숨긴 정상군 통과율 100%)로 AT-01~AT-04와 AT-07~AT-09를 교체한다.
